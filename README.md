
# AdEase - Wikipedia Traffic Forecasting

## 1. Project Overview

AdEase is an AI-powered advertising company that helps businesses
identify suitable languages and regions for digital advertising campaigns.

This project focuses on forecasting Wikipedia page views using
time-series forecasting techniques.

## 2. Business Problem

AdEase wants to identify future traffic patterns across different
Wikipedia pages to make better advertising placement decisions.

The objective is to forecast page views and identify languages
and regions with potential advertising opportunities.

## 3. Project Objectives

- Analyze Wikipedia traffic patterns.
- Perform Exploratory Data Analysis.
- Identify trends and seasonality.
- Apply time-series forecasting.
- Implement SARIMAX forecasting.
- Compare actual and predicted page views.
- Develop an API for model predictions.
- Containerize the application using Docker.
